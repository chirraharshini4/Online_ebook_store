📚 Online Ebook Store

A simple web-based ebook store developed using HTML, CSS, and JavaScript, featuring user registration, login, and a shopping cart interface.

✨ Features

- 📖 Online ebook store interface
- 🔐 Login and registration pages
- 🛒 Shopping cart functionality
- ✅ Client-side form validation using JavaScript
- 🎨 Custom styling with CSS

🛠️ Tech Stack

HTML • CSS • JavaScript

🚀 How to Run

1. Clone or download the repository.
2. Open "index.html" in your browser.
3. Explore the ebook store.

🎯 Objective

To implement client-side form validation using JavaScript in an online ebook store application.
